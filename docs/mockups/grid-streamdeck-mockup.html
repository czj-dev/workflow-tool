mockup 交互说明（方案 B：键面 + preset 色点）
· 点键身 = 跑默认参数（有必填无默认时进表单；运行中点击 = 回输出视图）
· 点 preset 色点 = 零跳转直跑该 preset；实心 = 最常用；≤3 个常驻，更多收成 +N
· 点 ⚙（hover 键面右上角出现）= 展开详情 Popover：描述 / 参数 / preset 列表（数字键 1-9 直选）/ RUN
· 左上角状态点：常灰 = 空闲，亮橙脉动 + 顶沿流光 = 运行中（见「清数据」）
· 快捷键：Popover 打开时按 1-9 直跑对应 preset，Esc 关闭
