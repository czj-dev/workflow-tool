mockup 交互说明（方案 C：键面翻转）
· 有 preset 的键：hover / Tab 聚焦 → 键面原地向上翻转，背面是操作面：首行 = 默认行为（直跑或进表单），下为 preset 行（全宽、名字完整、点击直跑），>3 收成 +N（进表单）
· 无 preset 的键：不翻面，hover 只提亮，点击即跑（不打断操作流）
· 正面底部 4px 暗示点 = preset 数量（只说「有几个」，不假装能读字）；无 preset 空占位保持整排同构
· 正面图标盒底色 = 使用足迹浓度 ····· 越常用越亮（示例：「详情」40 最亮，「卸载」10 未用过）
· 运行中：左上脉动点 + 顶沿流光（见「清数据」）；背面主行 go 位变 ↩ = 回输出视图
· Tooltip 取消：详情/参数精读进表单看，键面信息自足；长描述挂原生 title
· prefers-reduced-motion：翻面降级为淡入淡出（CSS 已写）
