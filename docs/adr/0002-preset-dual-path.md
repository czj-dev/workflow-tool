# 预设选择采用双路径：长按 hub 开环 + 展开态 chips

Action 的预设选择保留既有折扇环交互（复用 ActionPresetRing，动画零改动），锚点迁到紧凑态卡头图标 hub：长按 450ms hub 形变开环，盖盘与卡面氛围色同源（运行卡自动回落 primary）。展开态不出环，预设平铺为虚线 chips——紧凑态给快选，展开态给浏览，一条能力两条路径。

## Considered Options

- 弹出菜单 / 右键菜单：可发现性好，但引入全新控件语言，折扇环资产作废。
- 双路径（长按环 + chips）：零新增控件，代价是长按为隐藏手势。

## Consequences

- 隐藏手势依赖紧凑态预设点阵暗示可发现性；点阵只出现在有预设的卡上。
- 指针移动超过阈值判定为滚动意图，取消蓄力；环展开期间与展开态互斥。
